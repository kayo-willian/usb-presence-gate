# Threat model outline

**Asset.** Availability of explicitly selected noncritical lab services should follow the operator's physical USB presence policy. The host must retain SSH, network connectivity and console recovery in every supported transition.

**Trust boundary.** Trust the administrator, system manager, kernel, unit definitions and root-owned configuration, applied state and installation paths. Treat USB fields as hostile. A remote non-root user and an administrator who forgets to stop a service are in scope. An enrollment is identifier-only. Descriptors are clonable. Enrollment rejects missing or ambiguous serials.

**Limits.** Root compromise, physical boot access, stolen or emulated devices, BadUSB/HID and direct access outside the managed units exceed this mechanism. Revocation can remove a stolen device's eligibility. A process or connection surviving its unit stop is relevant when deciding whether that unit is eligible. SSH authentication and device authorization remain independent controls.

**Exposure.** From physical removal, account for event delivery or next successful scan, manager scheduling and lock delay, enumeration/settle, remaining grace, any delay to the expiry check, and actual stop completion. Some intervals can overlap. Verification adds latency to knowledge of closure. Enforcement (S2) requires an enabled, active internal safety timer even when udev is working. If udev misses a removal, include the wait for the next successful timer-driven scan in the exposure window. A stalled scan, an unreachable manager or a service that cannot stop leaves no demonstrated finite bound.

**Evidence as of 2026-11-22.** The physical Debian 13 notebook verified the disposable demo's USB removal/stop, reconnection/start, a denied ordinary manual start, post-reboot recovery and Python-independent emergency closure. The exact end-to-end stop bound, timer-only fallback, hostile cloning, corrupt policy on hardware and manager/kernel failures remain unverified. Some paragraphs above describe a **proposed generic gate**, which is not implemented. Refer to [the actual demo boundary](demo-safety.md) and [README](../README.md). Audit state changes and treat descriptor fingerprints as linkable data, never cryptographic proof.
