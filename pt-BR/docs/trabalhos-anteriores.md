# Trabalhos anteriores

- Henrique (rique-decoder) inspirou este projeto por meio de seu projeto educacional linux-usb-security-token, que explora identificadores USB em um fluxo de login PAM/GDM. O repositório indica licença MIT. O mecanismo de intertravamento proposto controla a disponibilidade de serviços selecionados em um host headless. [Projeto e licença](https://github.com/rique-decoder/linux-usb-security-token)
- USBGuard aplica autorização de dispositivos. O upstream declara licença GPL versão 2 ou posterior. Este projeto observa presença USB e pode, opcionalmente, controlar um serviço descartável fornecido. Não autoriza nem bloqueia dispositivos USB. [Licença do USBGuard](https://github.com/USBGuard/usbguard#license)

Essas referências descrevem abordagens relacionadas. Esta revisão não incorpora código upstream. Verifique a revisão upstream específica, a licença de cada arquivo e as obrigações de atribuição antes de considerar qualquer reutilização.
